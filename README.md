# SMAS Battle Online

Play the Super Mario All-Stars battle hack online with up to three friends.

**Play:** https://themanthemyththedan.github.io/smas-battle-online/

Open the link, pick your own *Super Mario All-Stars (USA)* ROM (the page
patches it in your browser; nothing is uploaded), create a room and send the
room link to your friends.

This repository only hosts the page and the patch (`battle.bps`). It contains
no ROM. It is generated by `scripts/publish_web.py` in the private project
repository; do not edit it by hand.

The emulator is [EmulatorJS](https://github.com/EmulatorJS/EmulatorJS)
(GPL-3.0), loaded from its CDN; connections are brokered by
[PeerJS](https://peerjs.com/).
